# Workshop submission

Prepared metadata is in `workshop-submission.json`. This is a local manifest, not a directly uploadable widget. Upload or paste **`widget.json`** as the content, and copy title, description and changelog from the manifest.

Sign into https://homarr.dev/workshop/ with GitHub, choose Publish, select customWidget and review every field. The Workshop does not install helper services from Git. Requires the included Python collector and a compatible UniFi OS console with a dedicated view-only account.

Run the setup and tests from INSTALL.md on a test deployment before submitting. No live account access or sanitized browser screenshots are bundled. Screenshots are optional; if adding them, use synthetic names/domains/addresses and no tokens or personal analytics. Never capture the production dashboard.

After publication record the actual listing URL/revision in this file and the root workshop manifest. Use Yours to update the existing submission rather than creating duplicates. Publishing needs your authenticated Workshop session. No submission has been created automatically.
