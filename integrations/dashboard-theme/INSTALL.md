# Installation

Export your board and save its current custom CSS. Paste `theme.css` into that board's custom CSS editor, save, and reload. Check desktop and mobile widths and your OS reduced-motion setting. No service or container restart is required.

For a terminal font, select a locally installed JetBrains Mono (or another monospace font) in your board settings. This CSS defines a fallback variable; it does not download a font or override every widget's font. If self-hosting fonts, upload your own licensed font and configure its URL privately. Set any desired background through Homarr rather than committing a personal image URL here.

Restore your saved CSS to roll back or uninstall. No dashboard layout export or credentials are included.
